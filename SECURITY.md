# Security Policy

## Supported Versions

Data Forge has not published its first tagged release. Security fixes currently
target the latest commit on `master`.

## Reporting a Vulnerability

Use GitHub's private vulnerability reporting for this repository. Do not open a
public issue or discussion for a suspected vulnerability.

Include the affected code or commit, a minimal reproduction, the impact, and
any suggested mitigation. You can expect an acknowledgement within seven days.
The maintainer will coordinate disclosure and a fix through the private report.
